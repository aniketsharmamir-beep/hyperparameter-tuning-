# Hyperparameter Tuning: Titanic Random Forest

## Objective
Tune a Random Forest with Grid Search and Randomized Search, and compare it with the default model.

## How to Run
1. pip install -r requirements.txt
2. python hyperparameter_tuning.py

## Files
- hyperparameter_tuning.py: the tuning script
- docs/tuning_report.md: process and results
- images/max_depth_effect.png: effect of max_depth
- data/: input and output tables
